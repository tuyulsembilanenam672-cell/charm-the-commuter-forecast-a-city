One line of weather for a city that does not exist — New Bumbershoot, where the drizzle is light, the sighs are heavy, and for once the buses are on time:

> In New Bumbershoot, expect light drizzle and heavy sighs; umbrellas up, spirits down, and for once the buses are on time.

Run with `node main.ts`; it writes the line to `/output/entry.txt`.
